# Student Record Manager – Module 2 Assignment

## Project Description

Student Record Manager is a web application developed for the Module 2 Assignment. It allows users to add, validate, save, and read student records.

## Features

* Add Student
* Validate Email using Regex
* Save Student Data to File
* Read Student Data
* Handle Invalid Input using Exceptions
* Search Student Records
* Delete Student Records
* 3D Interactive User Interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Regular Expressions
* JSON
* FileReader API
* Blob API

## How to Run

1. Open the GitHub repository.
2. Open `index.html`.
3. The Student Record Manager application will open in the browser.
4. Enter student details.
5. Click **Add Student**.
6. Use the file options to save or read student data.
