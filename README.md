# 🌐 StudentSphere 3D - Student Record Manager

A Python-based Student Record Manager developed for Module 2.

- Add Student
- Email Validation using Regex
- Save Student Data to File
- Read Student Data
- Search Student
- Delete Student
- Student Dashboard
- Exception Handling
- 3D-style User Interface

## Technologies Used

- Python
- Regular Expressions
- JSON
- File Handling
- Exception Handling
